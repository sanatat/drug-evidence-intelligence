# Examples

This repository does not ship real source PDFs because pharmacopoeial, regulatory, HTA, and journal documents may have licensing or redistribution restrictions.

To test the project:

1. create a private folder containing lawfully accessed PDFs;
2. place each drug's documents in a drug-named subfolder; or
3. start the web application and use `/upload`.

For public demonstrations, use synthetic PDFs or data you are licensed to redistribute.
