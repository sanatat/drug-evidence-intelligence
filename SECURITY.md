# Security

The web server binds to `127.0.0.1` by default and is intended for local research use.

Do not expose the application directly to the public internet without adding authentication, HTTPS, upload isolation, rate limiting, and deployment hardening. Uploaded PDFs are processed locally and may contain sensitive or licensed material.

If you discover a security issue in the code, please report it privately to the repository maintainer rather than opening a public issue containing exploit details.
